# Human Templates

Place real, licensed, studio-neutral human templates here for neural VTON.

Recommended structure:

```text
human_templates/
  neutral/
    balanced_soft.jpg
    wide_shoulder.jpg
    wide_hip.jpg
    straight_frame.jpg
    athletic_compact.jpg
    full_soft.jpg
  full/
    full_soft.jpg
  petite/
    straight_frame.jpg
```

These files are intentionally not generated procedurally. Neural providers such
as Replicate or Hugging Face Spaces should receive realistic person photos, not
the local fit diagram mannequin.
